# Contributing

This repository is a read-only mirror. Changes are made in our own repository
and published here, so pull requests are closed automatically. Issues are
welcome.

## Issues

Open an issue for a bug, unclear output, a question about the format, or a pack
that verifies when it should not (or fails when it should pass). Include:

- the output of `ares-verify --version`;
- the full report, as `--json` if you can;
- how the pack was produced. Attach the pack only if you are allowed to share
  it: a replay pack holds the records of real sessions.

## Security

If you find a way to make a tampered or forged pack pass, report it privately
with GitHub's "Report a vulnerability" on the Security tab, not in a public
issue.
